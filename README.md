# 简介 

本项目通过Windows操作系统的批处理脚本(.bat)控制mpv程序，进行有条件地自动化播放

  <a href="./README.EN.md">🌏English/中文</a>
</div>

# 使用场景
- 加入电脑自启动列表，实现开机播放音乐
  - 可以调整*时间间隔*参数,实现一日内仅播放一次音乐，开始美好的一天

# 运行逻辑
- 当脚本被启动时，自动从playlist.txt文件中选取一首音乐播放
- 被播放的音乐文件会被记录在played.txt文件里，在此文件中的音乐，除非全部音乐都被记录在played.txt文件内，否则该音乐不会再被播放
- 一次启动仅会调用mpv播放一首音乐

# 功能结束
## 时间间隔
- 现在的时间与上一次启动时的时间的差值(精度：小时)与配置的**时间间隔时长**参数比较，小于则不播放，大于播放
- 若上一次播放为和本次播放不为同一天(00:00为一天的分割线)，不考虑上文的比较结果，直接播放音乐

# 配置文件
## *playlist.txt*
配置播放的音乐
- 每一行添加音乐文件的相对或绝对路径
## *config.txt*
填入运行的必要参数和控制功能的开启和关闭
- 绝对不能留空
- 功能的开启或关闭，填入true或false
- 参数按照配置文件内的提示来填写
```config.txt
=基础=======================
·mpv.exe程序路径
mpv\mpv.exe
·播放音量（数值）（默认60）（范围0~100）
60
=功能=======================
·时间间隔（true/false）（默认false）
false
·时间间隔时长（数值/小时）（默认5）
5
============================
注意事项:每一项都不能留空
```
# 安装及使用
## 依赖mpv的安装
- 进入https://github.com/zhongfly/mpv-winbuild/releases
- 找到对应自己系统的版本下载
- 将其解压后保存在电脑中的任意地方，或与脚本放在同一目录
## 脚本的安装
- 进入[发布页面](https://github.com/huanls/Auto-play-music/releases "Release")下载mian.zip
- 解压main.zip文件到任意位置
- (可选)将解压的mpv文件夹移动到解压main.zip文件后的文件夹内
- 若干次运行*启动音乐.bat*文件，待脚本将配置文件补全，也需要每次按照终端的提示编辑配置文件

配置完成，感谢使用本脚本😊😊😊

# 补充
## 停止音乐播放
- 使用控制台(cmd)杀死mpv进程(也可以写成bat脚本)
```bat
taskkill /f /im mpv.exe
```
